# Workspace Guidelines & Rules

## Theme and Vendor Assets Read-Only Policy
- Files and folders inside `vendors/`, `css/`, `js/`, `media/`, `fonts/`, and `images/` (and all theme assets) are strictly read-only.
- **NEVER** edit, modify, overwrite, or delete files in these folders.
- Only reading, fetching, inspecting, and referencing these files is allowed.
- Custom styles and scripts must be written inside application PHP pages or dedicated custom script files, never by altering vendor/theme assets.
